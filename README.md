# Parker

Parker is a web application designed to help drivers quickly understand how difficult it is to find parking in different areas. Instead of searching for individual parking lots or driving around looking for a space, Parker provides a visual overview of parking difficulty across a map.

## Purpose

Finding parking in unfamiliar or busy areas can be frustrating and time-consuming. Parker aims to simplify this process by displaying a color-coded map that indicates the general difficulty of finding parking in different locations.

- 🟢 Green – Easy to find parking
- 🟡 Yellow – Moderate parking difficulty
- 🔴 Red – Very difficult to find parking

## Features

- Interactive map displaying parking difficulty by area
- Color-coded visualization for quick decision making
- Information about nearby parking options (planned)
- Parking restrictions and availability information (planned)
- User-contributed parking reports (planned)

## How It Works

Parker estimates parking difficulty by combining publicly available map and parking data with information about nearby destinations and parking facilities. As the project grows, additional data sources and user reports can be incorporated to improve the accuracy of the parking estimates.
